# 책꾸 (CHEKKU) - 설치 및 실행 가이드

## 시작 전 준비

### 1. Gemini API 키 발급
1. [Google AI Studio](https://aistudio.google.com) 접속
2. 우측 상단 "Get API Key" 클릭
3. "Create API key" → 키 복사

### 2. 환경 변수 설정 (선택사항)
앱 실행 후 UI에서 직접 입력 가능하므로 생략해도 됩니다.
```
.env.example → .env 로 복사 후 API 키 입력
```

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 접속

## 주요 기능

| 화면 | 기능 |
|------|------|
| 홈 (🏠) | 주간 독서 캘린더 스트립, 오늘의 기록 |
| 메모 (💬) | 독서 메모 작성 (스티키 노트 형식) |
| Chat KKU | AI 저자 페르소나와 1:1 대화, 스티커 자동 생성 |
| 캘린더 (📅) | 월간 스티커 캘린더, 통계 |

## 앱 사용 흐름

1. API 키 입력 (최초 1회)
2. 읽고 있는 책 선택
3. 독서 중 메모 작성
4. "AI와 대화" 버튼으로 저자 페르소나와 논쟁
5. 대화 종료 → 스티커 자동 생성 → 캘린더에 저장
